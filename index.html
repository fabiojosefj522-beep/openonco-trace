OpenOnco-Trace

Rastreabilidade de custódia e validação de amostras biológicas para terapias personalizadas contra o câncer, como CAR-T e vacinas de mRNA.

Parte A SDK e componente, open source (Apache-2.0) Parte Z API Enterprise, simulada nesta página
  1. Valide sem chave: a API responde 402 e o badge entra em modo sandbox.
  2. Troque para chave inválida e valide de novo: mesmo bloqueio, outro motivo.
  3. Use a chave Enterprise: HTTP 200 com hash SHA-256, assinatura e selo.
  4. Verifique a integridade do recibo; depois altere um caractere do JSON e verifique outra vez.
  5. Simule uma excursão térmica e acompanhe verde, amarelo e vermelho ao vivo.
  6. Teste os cenários vermelhos: paciente divergente, baixa celularidade e payload malformado.

Licença da API

Só nesta demo a chave fica no navegador. Em produção, ela vive no backend do sistema hospedeiro (BFF/proxy) ou é trocada por um token OAuth2 de curta duração.
