How it works

  1. 1

    Capture and check

    The SDK validates the sample against the schema and runs the open rules offline: patient identity, temperature, viability and custody order.

  2. 2

    Seal

    The API re-checks everything on the server clock, then issues a SHA-256 hash, an ES256 signature and a hash-chained audit entry.

  3. 3

    Verify anywhere

    Hospitals, auditors and partners verify the seal with the published key. No account, no license.

Your first sealed sample in a few lines

One script tag or one import. The API key stays on your backend; the browser only talks to your proxy.

Ships as ES module, CommonJS and plain script, with TypeScript types generated from the schema. npm packages are coming soon; until then, load it from jsDelivr.

index.html
<!-- 1. Load the SDK and the component -->
<script src="https://cdn.jsdelivr.net/gh/fabiojosefj522-beep/
  openonco-trace@v1.0.0/packages/sdk/openonco-sdk.js"></script>
<script src="…/packages/badge/onco-badge.js"></script>

<onco-badge id="badge"></onco-badge>

<script>
  // 2. Point it at your backend proxy
  const sdk = new OpenOncoSDK({
    endpoint: 'https://your-backend/openonco',
    operator: { userId: 'qa.asouza', printedName: 'Ana Souza' }
  });

  // 3. Track, show and seal
  const rec = sdk.track(sample);
  badge.sdk = sdk;
  badge.sampleId = rec.sampleId;
  const result = await sdk.submit(rec.sampleId);
</script>

Built for regulated custody

Chain of identity checks

The patient on the label must match the manufacturing order. A transposed digit stops the line before it reaches the patient.

Live thermal watch

Data-logger readings are re-evaluated as they arrive: verified, thermal attention or critical, with excursions kept on record.

Viability gates

Cell viability for apheresis, tumor content for biopsies and stability windows per material type.

Compliance controls built in

Audit trail, signature manifestation and record linking as in 21 CFR Part 11 (11.10(e), 11.50, 11.70), mapped to Anvisa RDC 658/2022, IN 134/2022 and IN 270/2023.

Privacy by schema

Pseudonymous IDs only. Names, national IDs and unknown fields are rejected before they leave the browser.

Open core

SDK, web component, schema and API spec under Apache-2.0. Run the checks yourself; pay only for sealed samples.
