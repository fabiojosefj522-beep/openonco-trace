# Código de Conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: participe com respeito, aceite críticas construtivas e foque no que é melhor para a comunidade e para os pacientes que dependem de software como este. Assédio, linguagem discriminatória e exposição de dados privados de terceiros não são tolerados.

**Como reportar:** use o reporte privado do GitHub (aba **Security** > **Report a vulnerability**, informando que se trata de conduta) ou contate os mantenedores diretamente. Os relatos são tratados com confidencialidade.
